CODE TOOL (Termux)
------------------
Tool nay co menu, khong can nho lenh dai.

1) Dat 2 file nay cung thu muc:
   - index.html
   - code_tool.py

2) Chay:
   python code_tool.py

3) Trong menu:
   1. Tao code moi
      - Chon so luong
      - Chon so vang
      - Chon so ruby
      - Chon code dung 1 lan hay nhieu lan
   2. Xem danh sach code
   3. Xoa code
   4. Dong bo code vao game

Quan trong:
- Moi code luon gom dung 8 chu so.
- Khi tao/xoa code, tool tu dong cap nhat bang REDEEM_CODES trong index.html.
- Vi vay code vua tao co the nhap truc tiep trong:
  Game -> Cai dat -> Nhap code.
- codes.json la file luu danh sach code. Hay giu lai neu muon quan ly cac code da tao.

Neu dang dung server.py, sau khi tool cap nhat index.html thi reload trang game de trinh duyet nap ban moi.
